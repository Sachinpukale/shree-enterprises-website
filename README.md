## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- Node.js (a supported LTS version)
- npm
- Git

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Replace the placeholder with your actual GitHub repository URL.

### 2. Open the project directory

```bash
cd <YOUR_PROJECT_FOLDER>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the website

Visit [http://localhost:3000](http://localhost:3000) in your browser.

The development server automatically reflects changes made to supported project files.

## 💻 Development Guidelines

- Use JavaScript for components and application logic.
- Use Bootstrap classes for layout and responsive styling where practical.
- Keep reusable UI components inside `src/components/`.
- Keep page-specific code organized within the `src/app/` directory.
- Follow the existing naming conventions and project structure.
- Do not commit `node_modules/`, `.next/`, real `.env` files, credentials, or other secrets.
- Test your changes locally before pushing them to GitHub.
